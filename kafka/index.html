QUESTION 02

Event 刚出生时，身体里有什么？

此刻它只活在 order-service 的 JVM 堆内存中。

// ① 业务对象：还不是 Kafka 字节
var event = new OrderCreated("A1024", 99.80);

// ② Headers 在链路追踪、多租户中很常用
var headers = new RecordHeaders()
  .add("traceparent", traceBytes)
  .add("tenant-id", tenantBytes);

// ③ partition = null，让 Producer 根据 key 选择
var record = new ProducerRecord<String, OrderCreated>(
  "orders.created", null, null,
  "user-9527", event, headers
);

producer.send(record);

记住一句话 key 决定“去哪”，value 是业务内容，headers 携带横切上下文。

QUESTION 03

调用 send()，会立刻写 Socket 吗？

不会。Producer 用两个线程把业务调用与网络 I/O 解耦。

PHYSICAL HOST · order-service-7d9f
JVM PROCESS · PID 18420
业务线程 · http-nio-8080-exec-7
共享缓冲区
后台线程 · kafka-producer-network-thread
send() ≠ 每条消息一次网络请求

关键分界 正常时异步入队；Metadata 未就绪或 Buffer 满时，send 可在 max.block.ms 内阻塞。

QUESTION 04

QUESTION 09

QUESTION 12

Topic、Partition、Segment，到底怎么套？

Topic 是逻辑命名；Partition 才是有序日志；Segment 是日志滚动后的文件组。

层级关系 Topic → Partition → Segment → RecordBatch → Record。

QUESTION 13

一个 Segment，为什么不是一个文件？

.log 保存真实 RecordBatch；稀疏索引帮助 Broker 少扫一段文件。

不要混淆 offset 是日志逻辑位置，file position 是 .log 文件中的字节位置。
